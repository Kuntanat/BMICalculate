# BMI Calculator - CS364 Assignment 1

แอปพลิเคชันสำหรับคำนวณดัชนีมวลกาย (Body Mass Index : BMI)

## Features (คุณสมบัติของแอปพลิเคชัน)
- คำนวณค่าดัชนีมวลกาย (BMI) จากน้ำหนักหน่วยกิโลกรัม และ ส่วนสูงหน่วยเซนติเมตร

จำกัดการกรอกตัวเลขได้ไม่เกิน 8 หลักก่อนจุดทศนิยม และไม่เกิน 2 หลักหลังจุดทศนิยม

แสดงค่า BMI เป็นทศนิยม 2 ตำแหน่ง พร้อมผลการจัดระดับน้ำหนัก

- รองรับภาษาไทยและภาษาอังกฤษตามภาษาที่ตั้งค่าในอุปกรณ์

- มี Layout รองรับสำหรับหน้าจอแนวตั้งและแนวนอน
